# PowerShell Admin Toolkit

A collection of PowerShell scripts for Windows Server, Active Directory, Exchange Online, Microsoft 365, and infrastructure administration.

> Designed for system administrators managing production environments. Most scripts are read-only by default unless clearly stated otherwise.
