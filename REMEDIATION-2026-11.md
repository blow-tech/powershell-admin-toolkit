# Script remediation — 8 November 2026

Reconciles the prior unmerged safety branch with main b33d8a3, preserving newer scripts. Nothing is merged or deployed.

New corrections:
- CleanupInactiveUsers: all-DC queries must complete; per-GUID observations must exist on every DC. Missing/zero/future timestamps are UNKNOWN. New users, adminCount/service-principal accounts and supplied exclusions cannot be acted on. A reviewed CSV of ObjectGUID values and matching SHA256 is mandatory for one explicit action. Default is report-only; each mutation uses ShouldProcess. Use a protected manifest; a digest is not a signature. AD observations are not atomic and do not prove inactivity; privileged/service ownership and all DCs must be validated in a lab.
- Create Multiple AD user: no module auto-install or workbook passwords. Validated domain/OU and whole-input preflight, collision rejection, preview by default, disabled creation, SecureString provider, terminating creation and immutable GUID group assignment. On a mid-run failure, inspect newly created disabled accounts; no automatic rollback or re-enabling occurs. Validate forest-wide UPN policy separately.
- Get-Member from Group and Get all servers in AD: explicit server/scope, fixed parsing, one query, structured buffered output, no implicit dependency installation, no output overwrite. Group export now uses CSV rather than XLSX.
- GetMailboxes and Export All Mailboxes: one maintained collector; expected-tenant existing session, type arrays, terminating errors, single publication. Old password/GUI/auto-connection parameters are removed.
- MailboxesUserCanAccess: reports direct assignments, preserving actual rights, Deny and inheritance. Queries each mailbox once per permission kind and caches principal resolution. Unknown principals remain explicit; this is NOT an effective-access or nested-group assessment.
- GetAllSharingLinks: explicit site/certificate scope and owned connection; single UTC snapshot, same-day expiry, mutually exclusive filters, no auto-install/plaintext password/GUI, no publication after a failed query. Selected visible libraries only; inherited/tenant-wide effective access and PnP version compatibility require lab validation.
- ReportSafety: refuses wrong/ambiguous Exchange sessions and existing report paths; same-directory temporary CSV publication. Pre-provision protected output parents.

Retained September fixes and migration requirements remain documented in REMEDIATION-2026-09.md. New test suite uses mock AD/Exchange operations only. Windows PowerShell 5.1 and PowerShell 7 CI are required; source parsing and mocks are not platform integration. CA/system-state restore, application recovery, Exchange/PnP/Graph permissions and large legacy health/group/inventory collectors remain lab/review gates. No benchmark claims.

Windows CI found that the main-branch filename `ExchangeOnlineGetMailBoxPermissions.` cannot be checked out on Windows. It is renamed to `ExchangeOnlineGetMailBoxPermissions.ps1` and delegates to the maintained permission-evidence collector; legacy Basic-auth remoting and incorrect Send-As query are removed. `Monitor-AD.ps1` depended on four absent Modules files and configured notifications with plaintext secrets. It now delegates to the maintained read-only AD collector with an explicit ReportPath; old notification/configuration options are removed.

## Further pending-review fixes (8 November)

- `AD_Health_Replication.ps1` and `Monitor-AD.ps1` now delegate to `Advanced-AD-HealthCheck.ps1`; both require DomainName and ReportPath. The retired forest-wide/native/notification interfaces are deliberately removed; Git retains their source. Extended native forest diagnostics are explicitly NotAssessed/UNKNOWN, not a passing health claim. Environment Health-Check adds an explicit domain, optional bounded TCP probes, event caps, validated thresholds, no-overwrite output and ShouldProcess mail control.
- Group management now defaults to WhatIf unless Execute is supplied, requires an explicit domain, hashes and parses the same CSV bytes, rejects ambiguous deleted-group names, scopes LDAP delegation, uses unique logs and preserves failure exit status. Bulk also requires ExecuteBulk and the reviewed CSV hash. Multi-step directory changes remain non-transactional; pilot and ACL/restore tests are mandatory.
- `Get-Inactive-AD_Users.ps1` now correlates exact unique EmployeeID values with supplied HR snapshots; removes fuzzy-name matches, undeclared helpers and implicit input paths. Missing HR/logon evidence remains UNKNOWN; it never authorizes cleanup. `GetAdUsersWithPasswordLastSetOlderThan.ps1` now actually applies its parameterized age filter.
- PIM audit now emits raw role-change evidence with explicit UTC windows, unique paging sessions, short-page continuation, record-cap/repeated-page rejection and one final CSV. Automatic mail, HTML and implicit connections are removed. PIM attribution is explicitly NotAssessed: this report is not a complete PIM inventory. Narrow windows if the service cap is reached.
- External trace uses V2 with explicit expected tenant and a maximum ten-day interval within service retention; continues after short pages, guards repeated cursors, deduplicates, limits memory and spaces requests. A failed/throttled query aborts publication; no blind replay of paging sessions. General queries do not prove complete coverage for messages with more than 1000 recipients; use MessageTraceId for those. Microsoft docs: https://learn.microsoft.com/powershell/module/exchangepowershell/get-messagetracev2 and https://learn.microsoft.com/powershell/module/exchangepowershell/search-unifiedauditlog .
- Distribution-list trace preserves input bytes, requires the expected existing tenant session, accepts only SMTP aliases, rejects ambiguity and reports supplied evidence without claiming inactivity. Shared mailbox sizes preserve service-returned raw size values instead of locale-dependent byte parsing; primary-mailbox scope only. Both remove implicit installation, credentials, GUI and session disconnection.
- Disabled group-user report uses the expected Graph context, terminating queries, buffered CSV, explicit missing AccountEnabled state and direct-user scope; unsupported/hidden/nested membership remains outside completeness claims.
- `ExchangeOnlineGetMailboxLocations.ps1` is retired with an actionable terminating message. Legacy Basic-auth remoting and unverified physical-location inference from server prefixes are not supported; use authoritative Microsoft 365 residency evidence. This is a blocked capability, not a replacement location audit.
- `Audit.ps1` is now a bounded, explicitly targeted CIM collector. `systeminfo_report.ps1` delegates to it. CSV sections contain JSON data and Collected/Empty/UNKNOWN state; legacy HTML, event, software and boot.ini sections are removed. Missing required evidence produces a nonzero failure after publishing clearly marked partial evidence. It never queries Win32_Product.
- Break-glass reports require explicit accounts/server/output, preinstalled AD tooling and unique resolved eligible identities. Disabled/locked/expired accounts cannot satisfy redundancy; unavailable DC evidence is not a pass. Manual/error weights stay in the denominator. Last logon is not proof of a successful recovery test; password/DSRM separation remains manual. No readiness certification or automatic RSAT installation.
- Resource monitoring caps requested samples at 10000 and uses unique no-clobber filenames. Entra device/risky-user outputs use platform-independent paths; risky lookback is validated and UTC-based.
- Sharing links now releases returned connection objects without an unsupported Disconnect-PnPOnline parameter; removes an unused per-item property call. Same-day expiry and denied queries are covered by mocks.

### Validation and deployment gates

All 65 PowerShell files (including extensionless scripts and tests) parse locally on PowerShell 7.4.13. All three isolated suites pass, covering denied/empty/unknown collectors, cleanup preservation, AD move rollback, creation collisions, tenant mismatch, paging/caps, literal permission principals/rights/deny, same-day sharing expiry, CIM scope and break-glass score completeness. Windows PowerShell 5.1 and PowerShell 7 CI must pass on the final commit. Mocks do not establish AD/Exchange/Graph/PnP/PowerCLI integration or API completeness.

Requires preinstalled ActiveDirectory/GroupPolicy tools appropriate to the server build; ExchangeOnlineManagement V3 (3.7.0+ for trace); supported Microsoft.Graph modules and PnP.PowerShell on their supported PowerShell runtime. Exact module versions, tenant cloud/licensing, delegated/app RBAC and certificate authentication must be validated in your lab. Use read-only recipient/statistics roles, Message Tracking and View-Only Audit Logs as applicable; Graph grants include AuditLog.Read.All, IdentityRiskyUser.Read.All or GroupMember.Read.All/User.Read.All only for the selected report. Do not default to Global Administrator. Output parents and manifests must be pre-provisioned with protected ACLs. Treat CSV fields as untrusted text when opening spreadsheets.

Compatibility changes are intentional: old GUI/auto-connect/credential switches, implicit domain scopes, location guessing and retired collector sections cannot be silently reused. Update every scheduler/caller and CSV consumer against this branch. Evidence buffers are bounded where documented; tenant-wide mailbox/group inventories can still require substantial resources. No benchmark is claimed. AD/CA/system-state/application restore, multi-step group changes, platform authentication and integration remain deployment blockers until documented lab tests succeed.

Compromised-account mutation actions and user-to-shared mailbox conversion now also require Execute; the default previews the resolved targets. Existing WhatIf/ShouldProcess controls remain.
