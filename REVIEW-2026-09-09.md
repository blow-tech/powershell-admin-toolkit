## Remaining findings, highest first

1. **High — platform recovery unverified:** CA backup, AD system-state backup and Linux application consistency still require full restore/recovery tests in a disposable lab. Output checks/checksums are not recoverability evidence. Protected storage, permissions, chains, service integration and scheduler migration are deployment blockers.
2. **High — incomplete health/security semantics:** large AD health/group-manager sections and break-glass scoring remain only partially reviewed. Break-glass code catches/falls back after unavailable DC observations and offers RSAT installation. These behaviors need fail-closed redesign and platform mocks before relying on scores.
3. **High — PIM report side effects/tenant scope:** `ExchangeOnline/Audit PIM role.ps1` still has an email path and module-install prompts; expected-tenant validation and full report semantics are unverified. The credential change does not make this script a safe unattended audit.
4. **Medium — legacy Exchange report correctness:** shared-mailbox statistics/quotas rely on formatted values; mailbox export passes a comma-containing recipient-type string; trace query windows/pagination/tenant behavior require complete API review. Five scripts no longer accept plaintext Password, but connection/module-install/disconnect behavior and existing-session ownership remain unresolved.
5. **Medium — legacy reporting correctness/compatibility:** remaining WMI collectors need error-state propagation, HTML escaping, PowerShell 7/CIM migration and local-versus-remote target checks (the hotfix query omits the remote target). Software collection is now explicitly NOT COLLECTED. No replacement software inventory is claimed.
6. **Medium — small helper scope/efficiency:** `createADObjectUnConstrainedDelegationRe.ps1` repeats forest scans and uses broad collection; `Find-Principal_PermAD.ps1` hard-codes a principal and changes working directory; `checkDCports.ps1` enumerates the forest and emits unimplemented UDP results. `Get_Sys_Info.ps1`, the two small disk reports and `Find-Badpasswd.ps1` lack consistent failed-collection signaling. Source review is complete, fixes are not.
7. **Medium — monitoring/integration:** resource counter names remain Windows/locale-dependent; retained finite samples consume memory proportional to duration/interval; Linux server-stats uses fragile top/df parsing. Shared alert delivery is local only. No benchmarks or end-to-end delivery validation.
8. **Documentation:** historical README examples still contain inaccurate paths/parameters. Prominent migration notices supersede them; a complete documentation rewrite remains outstanding.

Performance expectations, not benchmarks: per-domain buffering prevents repeated cumulative GPO output; manager caching avoids repeated identical AD requests; Graph registration avoids the old per-user role/method query pattern; resource samples use a List instead of repeated array copies; removed MSI enumeration avoids that expensive provider. No numeric speedup is asserted.
